# Absorb charges beyond an authorized request bound

When an authoritative Usage Charge exceeds its validated Hold, ModelPass will capture only that Hold from the Customer's Balance and record the excess as a Usage Bound Shortfall outside Balance. ModelPass absorbs the shortfall permanently rather than creating debt, collecting it from a later Deposit, or hiding it by changing the authoritative Usage Charge; this preserves the Customer's prepaid authorization boundary while retaining the exact provider and markup evidence needed to diagnose a failed endpoint bound.
