# Fail closed on unprovable wallet state

ModelPass will reconcile Polar events and OpenRouter generation costs continuously and through scheduled full sweeps. It may replay missing local processing automatically only from authoritative provider evidence and through existing idempotency boundaries; it never invents a monetary result to make records agree. A missing, duplicate, or contradictory item creates a Billing Freeze only for the affected Customer, while stale or unavailable provider-wide evidence creates a Flow Pause for the affected money flow. Posted Balances remain readable, and either restriction clears automatically only after Reconciliation proves the relevant state complete and consistent.

Every reconciliation path emits restricted Audit Records and operator alerts. Launch does not include support or admin tooling for balance corrections, goodwill, manual Usage Charge reversals, or operator pause/resume/rerun actions. Until such tooling is designed, direct database intervention may affect only operational reconciliation or restriction state, must be auditable and reasoned, and must never edit or delete Ledger Entries or directly rewrite a resulting Balance.
